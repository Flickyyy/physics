# 📚 ЧИТШИТ: КОЛЕБАНИЯ И ОПТИКА

## 📊 МЕХАНИЧЕСКИЕ И ЭЛЕКТРОМАГНИТНЫЕ КОЛЕБАНИЯ

### 🔄 Гармонические колебания
- **Основные уравнения:**
  - Координата: $x(t) = a \cos(\omega t + \phi)$
  - Скорость: $v(t) = -a\omega \sin(\omega t + \phi)$
  - Ускорение: $a(t) = -a\omega^2 \cos(\omega t + \phi)$
- **Периоды и частоты:**
  - $T = \frac{2\pi}{\omega}$, $\nu = \frac{1}{T}$, $\omega = 2\pi\nu$
- **Средние скорости:**
  - Из крайнего положения до $x = a/2$: $\langle v \rangle = \frac{3a}{T}$
  - Из положения равновесия до $x = a/2$: $\langle v \rangle = \frac{6a}{T}$

### 🧲 Индуктивность
- **Катушка:** $L = \mu_0 \mu \frac{N^2 S}{l}$, где $S = \pi \cdot \frac{d^2}{4}$
- **Взаимная индуктивность тороида и провода:** $M = \frac{\mu_0 \mu N h}{2\pi} \ln\left(\frac{r_2}{r_1}\right)$
- **Магнитная постоянная:** $\mu_0 = 4\pi \cdot 10^{-7}$ Гн/м

### ⚡ Колебательный контур
- **Период:** $T = 2\pi\sqrt{LC}$
- **Частота:** $\omega_0 = \frac{1}{\sqrt{LC}}$
- **Заряд и ток:**
  - $q(t) = q_0\cos(\omega_0 t)$
  - $I(t) = -q_0\omega_0\sin(\omega_0 t) = I_m\sin(\omega_0 t)$
  - $I_m = U_m\sqrt{\frac{C}{L}}$
- **Энергия:**
  - Магнитная: $W_L = \frac{LI^2}{2}$
  - Электрическая: $W_C = \frac{q^2}{2C} = \frac{CU^2}{2}$
  - Полная: $W = W_L + W_C = \text{const}$
- **ЭДС самоиндукции:** $\mathcal{E} = -L\frac{dI}{dt}$
- **При равенстве энергий:** $W_L = W_C \Rightarrow \frac{LI^2}{2} = \frac{CU^2}{2} \Rightarrow I = U\sqrt{\frac{C}{L}}$

### 📉 Затухающие колебания
- **Напряжение/смещение:** $u(t) = u_m e^{-\beta t}\cos(\omega t - \phi_0)$
- **Коэффициент затухания:** $\beta = \frac{\alpha}{2m}$ или $\beta = \frac{R}{2L}$
- **Частоты:**
  - Собственная: $\omega_0 = \sqrt{\frac{k}{m}}$ или $\omega_0 = \frac{1}{\sqrt{LC}}$
  - Затухающая: $\omega_d = \sqrt{\omega_0^2 - \beta^2}$
- **Добротность:** $Q = \frac{\omega_0}{2\beta}$

### 📈 Вынужденные колебания
- **Уравнение:** $m\frac{d^2x}{dt^2} + \alpha\frac{dx}{dt} + kx = F_0\sin\Omega t$
- **Амплитуда:** $A(\Omega) = \frac{F_0/m}{\sqrt{(\omega_0^2 - \Omega^2)^2 + 4\beta^2\Omega^2}}$
- **Резонансная частота:** $\Omega_{res} = \sqrt{\omega_0^2 - 2\beta^2} \approx \omega_0\sqrt{1 - \frac{1}{2Q^2}}$
- **Отношение частот:** $\frac{\Omega_{res}}{\omega_d} \approx 0.9987$ (при $Q = 10$)

### 🔌 RC-цепь переменного тока
- **Импеданс:** $Z = \sqrt{R^2 + X_C^2}$, где $X_C = \frac{1}{\omega C}$
- **Сдвиг фаз:** $\tan\varphi = \frac{X_C}{R} = \frac{1}{\omega RC}$
- **При $\varphi = 45°$:** $X_C = R$ и $Z = R\sqrt{2}$
- **Амплитуда тока:** $I_m = \frac{U_m}{Z}$

## 🌈 ОПТИКА

### 🔍 Интерференция
- **Условия максимумов и минимумов:**
  - Максимум: $\Delta d = m\lambda$
  - Минимум: $\Delta d = (m+\frac{1}{2})\lambda$
- **Оптическая разность хода:**
  - Призма: $\Delta = n \cdot d \cdot (1-\cos\alpha)$
  - Пластинка (нормальное падение): $\Delta L = (n-1)h$
  - Пластинка (угол $\theta$): $\Delta L = n\frac{h}{\cos\theta'} - h\cos\theta$, где $\sin\theta = n\sin\theta'$

### 🌊 Интерференция в тонких плёнках
- **Нормальное падение (отражение):**
  - Максимум: $2nd = (m+\frac{1}{2})\lambda$ (учет сдвига фазы на π)
  - Минимум: $2nd = m\lambda$
- **Минимальные толщины:**
  - Для усиления: $d_{min} = \frac{\lambda}{4n}$
  - Для ослабления: $d_{min} = \frac{\lambda}{2n}$

### 🔆 Опыт Юнга и бипризма Френеля
- **Ширина полосы:** $\Delta x = \frac{\lambda D}{d}$
- **Расстояние между мнимыми источниками:** $d = 2a(n-1)\theta$
- **Длина волны:** $\lambda = \frac{\Delta x \cdot d}{b}$

### 🔦 Дифракция Френеля
- **Радиус k-й зоны:** $r_k = \sqrt{\frac{k\lambda ab}{a+b}}$
- **Число зон в отверстии:** $k = \frac{r^2(a+b)}{\lambda ab}$
- **Глубина выемки для фазового сдвига π:** $h = \frac{\lambda}{2(n-1)}$
- **Фокусное расстояние зонной пластинки:** $F = \frac{r_k^2}{k\lambda}$

### 📏 Дифракция Фраунгофера
- **На щели:**
  - Минимумы: $b\sin\theta = m\lambda$
  - Ширина центрального максимума: $\Delta x = \frac{2\lambda L}{b}$
- **На решётке:**
  - Максимумы: $d\sin\theta = m\lambda$
  - Условие отсутствия перекрытия порядков: $m\lambda_2 < (m+1)\lambda_1$
  - Разрешающая способность: $R = \frac{\lambda}{\Delta\lambda} = mN$

## 📝 СТРАТЕГИИ РЕШЕНИЯ ЗАДАЧ

### 📌 Колебания
1. **Начните с выявления типа колебаний:**
   - Свободные, затухающие или вынужденные
   - Механические или электрические

2. **Для LC-контура:**
   - Найдите собственную частоту $\omega_0 = \frac{1}{\sqrt{LC}}$
   - Выразите ток через заряд: $I(t) = \frac{dq}{dt}$
   - Используйте закон сохранения энергии

3. **Для затухающих колебаний:**
   - Определите коэффициент затухания $\beta$
   - Рассчитайте частоту затухающих колебаний $\omega_d$

4. **Для вынужденных колебаний:**
   - Проверьте условие резонанса $\Omega_{res} \approx \omega_0$
   - Найдите отношение $\beta$ к $\omega_0$ или определите добротность $Q$

### 📌 Оптика
1. **Для задач по интерференции:**
   - Определите оптическую разность хода
   - Учитывайте изменение фазы при отражении (если применимо)
   - Проверьте условия максимума/минимума

2. **Для дифракции Френеля:**
   - Вычислите радиус зон Френеля
   - Определите число зон в отверстии/преграде
   - Для зонных пластинок найдите оптимальную глубину выемки

3. **Для дифракции Фраунгофера:**
   - На щели: найдите углы минимумов и ширину максимумов
   - На решётке: рассчитайте углы максимумов и проверьте перекрытие порядков

## 🔢 ПОЛЕЗНЫЕ ЗНАЧЕНИЯ

  - Масло: n ≈ 1.5

  - Синий: λ ≈ 430-480 нм
