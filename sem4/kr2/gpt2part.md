## Домашнее задание №7

### 1. Оптическая разность хода через призму
**Условие:** два параллельных пучка I и II падают на стеклянную призму с углом α = 30° и выходят из неё.  
**Найти:** Δ — оптическая разность хода после призмы.

**Решение:**  
1. При прохождении через призму один из лучей проходит толщину D = t/ cos β, другой — меньше.  
2. Для призмы с углом α толщина в средней части t = h·sin(α/2)/sin β (где β — угол преломления).  
3. Закон Снеллиуса: n·sin β = sin α/2.  
4. Оптическая разность хода:  
   $$
   Δ = (n - 1)\,t = (n-1)\,\frac{h\sin(\alpha/2)}{\sin\beta}.
   $$  
5. Подставляем: β = arcsin(sin(15°)/n). Если n не дан — оставляем ответ в общем виде.

### 2. Длина отрезка в вакууме
**Условие:** на отрезке ℓ₂ = 3 мм в воде укладывается ровно столько же λ₂, сколько λ₁ укладывается на отрезке ℓ₁ в вакууме.  
**Найти:** ℓ₁.

**Дано:**  
- n_воды = n  
- λ₁ (вакуум), λ₂ = λ₁/n  

**Решение:**  
1. Число волн на ℓ₂: m = ℓ₂/λ₂ = ℓ₂·n/λ₁.  
2. Чтобы столько же λ₁ уложилось на ℓ₁: ℓ₁ = m·λ₁ = ℓ₂·n.  
3. ⇒ ℓ₁ = 3 мм·n_воды ≈ 3 мм·1,33 = 3,99 мм.

### 3. Бипризма Френеля
**Условие:**  
- a = 25 см (до щели), b = 100 см (до экрана)  
- преломляющий угол призмы θ = 20′ (минут) = 20/60° ≈ 0,333°  
- ширина интерференционной полосы Δx = 0,55 мм  

**Найти:** λ.

**Решение:**  
1. Угол отклонения α' ≈ (n−1)θ.  
2. Расстояние между виртуальными источниками d = 2a·tan α'.  
3. Шаг полос: Δx = (b·λ)/d ⇒ λ = (d·Δx)/b.  
4. Подставляем:  
   - α' ≈ (1,5−1)·0,333° = 0,1667° ⇒ tan α' ≈ 0,00291  
   - d ≈ 2·0,25·0,00291 = 0,001455 м  
   - λ = 0,001455·0,00055/1,00 ≈ 8,0·10⁻⁷ м = 800 нм.

### 4. Интерференция на мыльной плёнке
**Условие:** n = 1,3, λ = 0,55 мкм, падение нормально, в воздухе.

**Найти:** наименьшая d для максимума отражённого света.

**Решение:**  
1. При нормальном падении фаза на границе воздух–плёнка меняется на π (внутри меньше).  
2. Для максимума отражённого:  
   $$
   2n d = (m + ½)λ,\quad m = 0,1,2…
   $$  
3. Наименьшее (m=0):  
   $$d = \frac{λ}{4n} = \frac{0,55}{4·1,3} ≈ 0,106\,\text{мкм}.$$

### 5. Интерференция в клиновидной пластинке
**Условие:**  
- угол между гранями α = 1,03′ = 1,03/60° ≈ 0,01717°  
- средняя толщина b = 3,00 мм, длина l = 100 мм  
- λ₁ = 400 нм, при λ₁ видны полосы равной толщины на всём l  

**Найти:** x для λ₂ = 401 нм (такая же Δλ/λ).

**Решение:**  
1. Толщина пластинки постепенно меняется: d(x) = b + x·tan α.  
2. Интерференционная полоса соответствует d = k·λ/2n (k целое).  
3. При λ₁ на всём l d изменяется на Δd = l·tan α = m·λ₁/2n.  
   ⇒ m = 2n·l·tan α/λ₁.  
4. Чтобы получить m полос для λ₂, нужно x:  
   $$x·\tanα = m·\frac{λ₂}{2n} ⇒ x = \frac{mλ₂}{2n\tanα}.$$  
5. Подставляем m из пункта 3.

### 6. Цвет лужи при отражении
**Условие:** глаза на h = 1,85 м, плёнка масла n₁ = 1,5, вода n₂ = 1,33;  
λ_син = 0,43 мкм, λ_зел = 0,53 мкм.  

**Найти:** расстояние s, на котором лужа меняет цвет с синего на зелёный.

**Решение:**  
1. Луч до наблюдателя идёт по касательной к плёнке.  
2. Угол отражения φ = arccos(h/(h+s)).  
3. Оптическая разность хода между отражениями от воздуха–масла (π-фаза) и масла–воды (без) должна давать максимум для зелёного:  
   $$2n_1 d\cosφ = (m + ½)λ_{зел}.$$  
4. Для синего при более близком s: 2n₁d cosφ₁ = (m+½)λ_син.  
5. Делим: cosφ₂/cosφ₁ = λ_зел/λ_син ⇒  
   $$\frac{h+s_1}{\sqrt{h^2+(h+s_1)^2}} : \frac{h+s_2}{\sqrt{h^2+(h+s_2)^2}} = \frac{0,53}{0,43}.$$  
6. Решаем относительно s₂ (для зелёного), зная s₁→∞ (синий при близком) ⇒ приближённо:  
   $$s ≈ h\Bigl(\frac{λ_{зел}}{λ_{син}} - 1\Bigr)^{-½} ≈ 1,85\Bigl(\frac{0,53}{0,43} - 1\Bigr)^{-½} ≈ 5,0\,\text{м}.$$

## Дифракция Френеля

### 7. Зоны Френеля через круглое отверстие
**Условие:**  
- λ = 500 нм, a = b = 1 м, d = 2 мм.  

**Найти:** число зон k, укладывающихся в отверстии для точки P.

**Решение:**  
1. Радиус отверстия R = d/2 = 1 мм.  
2. Радиус k-й зоны:  
   $$
   r_k ≈ \sqrt{kλ\,\frac{ab}{a+b}} = \sqrt{kλ·\frac{1·1}{2}} = \sqrt{\frac{kλ}{2}}.
   $$  
3. Условие r_k = R ⇒  
   $$k = \frac{2R^2}{λ} = \frac{2·(10^{-3})^2}{5·10^{-7}} = 4.$$

**Ответ:** 4 зоны.

### 8. Зонная пластинка (квинтет)
**Условие:**  
- n, радиусы r₁=2 мм, r₂=4 мм, r₃=6 мм  
- шаг толщин h (одинаков)  
- λ = 500 нм  

**Найти:** максимальное Fₘₐₓ и оптимальное h, выигрыш в интенсивности.

**Решение (кратко):**  
1. Работа как фазо-преобразователь: каждая ступень добавляет π/2.  
2. Оптика: Fₘₐₓ ≈ r_n²/(nλ) при n ступенях.  
3. Оптимальное h = λ/(2(n−1)(n−1)), выигрыш ≈ n².

### 9. Выемка на пластинке, 1,5 зоны
**Условие:** плоская волна λ=0,6 мкм, n=1,5, выемка так, что P — 1,5 зоны.

**Найти глубину h для максимума в P.**

**Решение:**  
1. Разность хода = 2(n−1)h = (k + ½)λ, для k = 1 ⇒  
   $$h = \frac{3λ}{4(n−1)} = \frac{3·0,6}{4·0,5} = 0,9\,\text{мкм}.$$

### 10. Кольца выемок в пластине
**Условие:** концентрические выемки совпадают с границами нечётных зон.  

**Найти:** h для максимума в P.

**Решение:**  
1. Для нечётной зоны Δr = (2m−1)λ/2 ⇒ выемка должна дать фазовый сдвиг (2m−1)π.  
2. Разность хода 2(n−1)h = (2m−1)λ/2 ⇒  
   $$h = \frac{(2m−1)λ}{4(n−1)}.$$  
3. Для m=1: h = λ/[4(n−1)].

### 12. Ширина изображения щели
**Условие:** b = 20 мкм, λ = 500 нм, L = 1 м.

**Найти:** ширину между первыми минимумами.

**Решение:**  
1. Для m=±1: sinθ₁ = λ/b = 0,5/20 = 0,025 ⇒ θ₁ ≈ 1,43°.  
2. На экране x = L·tanθ₁ ≈ 1·0,025 = 0,025 м = 25 мм.  
3. Между двумя минимумами: 2x = 50 мм.

### 13. Решётка и линза
**Условие:** d = 4·10⁻⁶ м, f = 0,4 м, первый максимум на расстоянии l = 5 см.

**Найти:** λ.

**Решение:**  
Для решётки: d·sinθ = mλ, m=1. На экране x = f·tanθ ≈ f·sinθ.  
$$λ = \frac{d·x}{f} = \frac{4·10^{-6}·0,05}{0,4} = 5·10^{-7}\,\text{м} = 500\,\text{нм}.$$

### 14. Перекрытие спектров на решётке
**Условие:** d = 2 мкм, λ₁=500 нм…λ₂=600 нм.

**Найти:** перекроются ли спектры разных порядков.

**Решение:**  
Спектры m-го порядка лежат в углах θ_m = arcsin(mλ/d).  
Перекрытие между m-м λ₂ и (m+1)-м λ₁, если:  
$$m\,\frac{λ₂}{d} > (m+1)\,\frac{λ₁}{d} ⇒ mλ₂ > (m+1)λ₁.$$  
Для m=1: 1·600 > 2·500? 600 > 1000 — нет. Для больших m условие ещё менее вероятно.  
**Ответ:** не перекрываются.
