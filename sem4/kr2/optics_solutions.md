# Решения задач по оптике (интерференция и дифракция)

## Задача 1: Оптическая разность хода при преломлении через призму

**Условие:** Два параллельных пучка световых волн I и II падают на стеклянную призму с преломляющим углом α = 30° и после преломления выходят из нее. Найти оптическую разность хода Δ световых волн после преломления их призмой.

**Решение:**

Рассмотрим геометрический путь лучей через призму. Из-за параллельности пучков, угол падения и угол выхода у обоих пучков одинаковы. Разница возникает из-за дополнительного пути второго луча в призме.

1. Оптическая разность хода определяется как:
   Δ = n·d·(1 - cos α)
   
   где d - основание призмы, n - показатель преломления стекла.

2. Для призмы с преломляющим углом α = 30°:
   Δ = n·d·(1 - cos 30°) = n·d·(1 - 0.866) = 0.134·n·d

**Ответ:** Δ = 0.134·n·d, где n - показатель преломления стекла, d - основание призмы.

## Задача 2: Сравнение длин отрезков с одинаковым числом волн

**Условие:** Определить длину l₁ отрезка, на котором укладывается столько же длин волн в вакууме, сколько их укладывается на отрезке l₂ = 3 мм в воде.

**Решение:**

1. Число волн на отрезке l:
   N = l/λ
   
   где λ - длина волны в данной среде.

2. В воде длина волны меньше, чем в вакууме:
   λᵥₒₚₑ = λₒ/n
   
   где n = 1.33 - показатель преломления воды.

3. Приравняем числа волн:
   l₁/λₒ = l₂/(λₒ/n)
   l₁/λₒ = l₂·n/λₒ
   l₁ = l₂·n

4. Подставляем значения:
   l₁ = 3 мм · 1.33 = 3.99 мм ≈ 4.0 мм

**Ответ:** l₁ = 4.0 мм

## Задача 3: Бипризма Френеля

**Условие:** Расстояния от бипризмы Френеля до узкой щели и экрана равны соответственно a = 25 см и b = 100 см. Бипризма стеклянная с преломляющим углом θ = 20′. Найти длину волны света, если ширина интерференционной полосы на экране Δx = 0.55 мм.

**Решение:**

1. Ширина интерференционной полосы связана с длиной волны и расстоянием между источниками:
   Δx = λb/d
   
   где d - расстояние между мнимыми источниками.

2. Для бипризмы Френеля расстояние между мнимыми источниками:
   d = 2a(n-1)θ
   
   где n ≈ 1.5 - показатель преломления стекла, θ - преломляющий угол в радианах.

3. Переведем угол 20′ в радианы:
   θ = (20/60) · (π/180) ≈ 0.00582 рад

4. Рассчитаем расстояние между мнимыми источниками:
   d = 2 · 25 см · 0.5 · 0.00582 ≈ 0.1455 см

5. Найдем длину волны:
   λ = Δx · d/b = 0.055 см · 0.1455 см / 100 см ≈ 8.0 · 10⁻⁵ см = 800 нм

**Ответ:** λ ≈ 800 нм

## Задача 4: Интерференция в мыльной пленке

**Условие:** На мыльную пленку (n = 1.3), находящуюся в воздухе, падает нормально пучок лучей белого света. При какой наименьшей толщине d пленки отраженный свет с длиной волны λ = 0.55 мкм окажется максимально усиленным в результате интерференции?

**Решение:**

1. При отражении от границы воздух-пленка происходит изменение фазы на π.
2. При отражении от границы пленка-воздух изменения фазы нет.
3. Для максимального усиления необходимо, чтобы:
   2nd = (m + 1/2)λ, где m = 0, 1, 2, ...

4. Для минимальной толщины m = 0:
   2 · 1.3 · d = 0.5 · 0.55 мкм
   d = 0.55 мкм / (4 · 1.3) = 0.106 мкм

**Ответ:** d = 0.106 мкм

## Задача 5: Интерференция на клиновидной пластинке

**Условие:** Угол между гранями прозрачной клиновидной пластинки α = 1.03′. Средняя толщина пластинки b = 3.00 мм, длина пластинки l = 100 мм. При нормальном падении на пластинку света с длиной волны λ₁ = 400.00 нм, на половине длины пластинки наблюдаются интерференционные полосы равной толщины. На какой части пластинки x будут наблюдаться интерференционные полосы, если осветить пластинку светом с длиной волны λ₂ = 401.00 нм, степень монохроматичности которого λ/Δλ такая же, как у первоначального света?

**Решение:**

1. Число интерференционных полос на длине l₂ = l/2 = 50 мм определяется изменением толщины пластинки:
   N = 2Δb/λ₁
   
   где Δb - изменение толщины на длине l₂.

2. Изменение толщины клина:
   Δb = l₂ · tan α
   
   Переведем угол в радианы: α = (1.03/60) · (π/180) ≈ 0.000299 рад
   Δb = 50 мм · 0.000299 ≈ 0.015 мм = 15000 нм

3. Число полос с λ₁:
   N = 2 · 15000 нм / 400 нм = 75 полос

4. Для света с длиной волны λ₂ такая же степень монохроматичности дает то же число полос:
   N = 2Δb'/λ₂ = 75
   
5. Находим изменение толщины Δb':
   Δb' = 75 · λ₂/2 = 75 · 401 нм / 2 = 15037.5 нм

6. Находим новую длину x, на которой будут видны полосы:
   Δb' = x · tan α
   x = Δb' / tan α = 15037.5 нм / 0.000299 = 50.25 мм

7. Отношение x к полной длине:
   x/l = 50.25/100 = 0.5025

**Ответ:** x ≈ 50.25 мм или примерно 50.25% длины пластинки.

## Задача 6: Цвет масляной пленки на луже

**Условие:** Человеку, идущему по горизонтальному участку дороги в пасмурный безветренный день, небольшая лужа, видневшаяся вдалеке на дороге, показалась синего цвета. На каком расстоянии s от этой лужи она будет казаться человеку зеленой? Считать, что глаза человека находятся все время на высоте h = 1.85 м от дороги. Показатель преломления очень тонкой пленки бесцветного масла на поверхности лужи равен n₁ = 1.5, а воды – n₂ = 1.33. Длину волны света синего цвета считать равной λ_син = 0.43 мкм, а зеленого – λ_зел = 0.53 мкм.

**Решение:**

1. Условие максимума интерференции на тонкой пленке:
   2d·n₁·cos θ' = (m + 1/2)λ
   
   где θ' - угол преломления в пленке.

2. Связь угла падения и расстояния до лужи:
   tan θ = h/s
   
   Для малых углов: sin θ ≈ tan θ ≈ θ = h/s

3. По закону Снелля:
   sin θ' = sin θ/n₁ = h/(s·n₁)

4. Для малых углов cos θ' ≈ 1 - (θ')²/2 ≈ 1 - h²/(2s²n₁²)

5. Если для синего цвета на расстоянии s_син выполняется:
   2d·n₁·[1 - h²/(2s_син²n₁²)] = (m + 1/2)λ_син

   А для зеленого на расстоянии s_зел:
   2d·n₁·[1 - h²/(2s_зел²n₁²)] = (m + 1/2)λ_зел

6. Если это тот же порядок интерференции (m одинаково), то:
   [1 - h²/(2s_син²n₁²)]/[1 - h²/(2s_зел²n₁²)] = λ_зел/λ_син

7. Для малых углов можно приближенно считать, что:
   s_зел²/s_син² ≈ λ_син/λ_зел
   
   s_зел = s_син·√(λ_син/λ_зел) = s_син·√(0.43/0.53) ≈ 0.9s_син

**Ответ:** s_зел ≈ 0.9·s_син, то есть примерно на 10% ближе, чем точка, где лужа кажется синей.

## Задача 7: Число зон Френеля

**Условие:** Точечный источник S монохроматического света с длиной волны λ = 500 нм на расстоянии a = 1 м от преграды, представляющей экран с круглым отверстием, диаметр которого d = 2 мм. Сколько зон Френеля укладывается в этом отверстии для точки наблюдения P, находящейся на расстоянии b = 1 м?

**Решение:**

1. Радиус k-й зоны Френеля:
   r_k = √(k·λ·ab/(a+b))

2. Радиус отверстия r = d/2 = 1 мм

3. Находим максимальное число k зон, укладывающихся в отверстии:
   r² = k·λ·ab/(a+b)
   k = r²·(a+b)/(λ·ab)

4. Подставляем значения:
   k = (1 мм)²·(1 м + 1 м)/(500 нм·1 м·1 м)
   = (10⁻³)²·2/(5·10⁻⁷·1·1)
   = 4

**Ответ:** В отверстии укладывается 4 зоны Френеля.

## Задача 8: Зонная пластинка

**Условие:** Зонная пластинка, вырезанная из стекла с показателем преломления n, представляет собой тело вращения. Радиусы равны r₁ = 2, r₂ = 4 и r₃ = 6 мм. Толщина ступенек h одинакова. Определить максимальное фокусное расстояние F_max пластинки для света с длиной волны 500 нм. При какой толщине h интенсивность в фокусе будет наибольшей?

**Решение:**

1. Радиус k-й зоны Френеля для зонной пластинки:
   r_k = √(k·λ·F)

2. Подставим радиусы:
   r₁² = 4 мм² = 1·λ·F_max
   F_max = 4 мм²/(500 нм) = 8000 мм = 8 м

3. Проверка для других радиусов:
   r₂² = 16 мм² = 4·λ·F_max/4 = λ·F_max
   r₃² = 36 мм² = 9·λ·F_max/9 = λ·F_max

4. Для максимальной интенсивности в фокусе, фазовый сдвиг между соседними зонами должен быть π (или λ/2):
   (n-1)·h = λ/2
   h = λ/(2(n-1)) = 500 нм/(2·0.5) = 500 нм (при n = 1.5)

5. Максимальный выигрыш в интенсивности для зонной пластинки с 3 зонами:
   I/I₀ ≈ (2N)² = 36, где N - число зон (3)

**Ответ:** F_max = 8 м; h = 500 нм/(n-1); максимальный выигрыш примерно в 36 раз.

## Задача 9: Дифракция Френеля на пластинке с выемкой

**Условие:** Плоская световая волна с длиной волны 0.6 мкм падает нормально на большую стеклянную пластинку (n = 1.5), на противоположной стороне которой сделана выемка. Для точки наблюдения P она представляет собой полторы зоны Френеля. Найдите глубину выемки, при которой интенсивность света в точке P будет максимальной.

**Решение:**

1. Для максимальной интенсивности в точке P необходимо, чтобы внешняя половина зоны Френеля вносила такой же вклад, как и первая зона.

2. Для этого нужно изменить фазу внешней половины зоны на π радиан, что соответствует оптической разности хода λ/2.

3. Оптическая разность хода при прохождении выемки глубиной h:
   Δ = (n-1)·h
   
   Для максимальной интенсивности: (n-1)·h = λ/2
   
   h = λ/(2(n-1)) = 0.6 мкм/(2·0.5) = 0.6 мкм

**Ответ:** h = 0.6 мкм.

## Задача 10: Кольцевые выемки и дифракция Френеля

**Условие:** Между точечным источником c длиной волны λ = 500 нм и экраном расположена большая стеклянная пластина, в которой сделаны концентрические кольцевые выемки глубиной h. Эти выемки для точки наблюдения P экрана совпадают с границами нечётных зон Френеля. При какой глубине выемок интенсивность света в точке P будет максимальна?

**Решение:**

1. Для максимальной интенсивности необходимо, чтобы нечётные зоны Френеля (обычно дающие противофазный вклад) давали синфазный вклад с чётными зонами.

2. Для этого нужно добавить фазовый сдвиг π (180°) в нечётных зонах, что соответствует оптической разности хода λ/2.

3. Оптическая разность хода при прохождении выемки глубиной h:
   Δ = (n-1)·h
   
   Для максимальной интенсивности: (n-1)·h = λ/2
   
   h = λ/(2(n-1)) = 500 нм/(2·0.5) = 500 нм (при n = 1.5)

**Ответ:** h = 500 нм.

## Задача 11: Дифракция Фраунгофера - минимумы на щели

**Условие:** Свет с длиной волны λ падает нормально на длинную щель ширины b. Определите направление на минимумы освещенности.

**Решение:**

При дифракции Фраунгофера на одной щели минимумы интенсивности наблюдаются под углами θ, определяемыми условием:

sin θ_m = m·λ/b

где m = ±1, ±2, ±3, ... - целые числа, не равные нулю.

**Ответ:** Минимумы наблюдаются под углами θ, для которых sin θ = m·λ/b, где m = ±1, ±2, ±3, ...

## Задача 12: Ширина изображения щели

**Условие:** На щель шириной b = 20 мкм падает нормально параллельный пучок монохроматического света длиной λ = 500 нм. Найдите ширину изображения щели на экране, удаленном от щели на расстояние 1 м.

**Решение:**

1. При дифракции Фраунгофера первые минимумы находятся под углами:
   sin θ₁ = ±λ/b

2. Для малых углов sin θ₁ ≈ θ₁:
   θ₁ ≈ λ/b = 500·10⁻⁹/20·10⁻⁶ = 0.025 рад

3. Линейное расстояние от центра до первого минимума на экране:
   y₁ = L·θ₁ = 1 м·0.025 = 0.025 м = 25 мм

4. Полная ширина изображения щели (между первыми минимумами):
   W = 2·y₁ = 2·25 мм = 50 мм

**Ответ:** W = 50 мм.

## Задача 13: Дифракционная решетка и линза

**Условие:** На решетку с периодом d = 4·10⁻⁶ м падает нормально монохроматическая волна. За решеткой расположена собирающая линза с фокусным расстоянием f = 0.4 м, которая дает изображение дифракционной картины на экране. Определите длину волны λ, если первый максимум получается на расстоянии l = 5 см от центрального.

**Решение:**

1. Для дифракционной решётки условие максимумов:
   sin φ_m = m·λ/d

2. В фокальной плоскости линзы расстояние от центрального максимума:
   l = f·tan φ_m

3. Для малых углов tan φ_m ≈ sin φ_m = m·λ/d

4. Для первого максимума (m = 1):
   l = f·λ/d

5. Выражаем длину волны:
   λ = l·d/f = 5·10⁻²·4·10⁻⁶/0.4 = 5·10⁻⁷ м = 500 нм

**Ответ:** λ = 500 нм.

## Задача 14: Перекрытие спектров дифракционной решетки

**Условие:** На дифракционную решетку с периодом d = 2 мкм падает нормально свет, пропущенный через светофильтр. Фильтр пропускает длины волн от λ₁ = 500 нм до λ₂ = 600 нм. Будут ли спектры разных порядков перекрываться друг другом?

**Решение:**

1. Для дифракционной решётки условие максимумов:
   sin φ_m = m·λ/d

2. Проверяем перекрытие первого и второго порядков:
   sin φ₁,λ₂ = 1·600 нм/2000 нм = 0.3
   sin φ₂,λ₁ = 2·500 нм/2000 нм = 0.5

   Так как 0.3 < 0.5, первый и второй порядки не перекрываются.

3. Проверяем перекрытие второго и третьего порядков:
   sin φ₂,λ₂ = 2·600 нм/2000 нм = 0.6
   sin φ₃,λ₁ = 3·500 нм/2000 нм = 0.75

   Так как 0.6 < 0.75, второй и третий порядки не перекрываются.

4. Проверяем перекрытие третьего и четвертого порядков:
   sin φ₃,λ₂ = 3·600 нм/2000 нм = 0.9
   sin φ₄,λ₁ = 4·500 нм/2000 нм = 1.0

   Так как 0.9 < 1.0, третий и четвертый порядки не перекрываются.

5. Для пятого порядка:
   sin φ₅,λ₁ = 5·500 нм/2000 нм = 1.25 > 1

   Поскольку sin φ не может превышать 1, пятый и более высокие порядки физически не наблюдаются.

**Ответ:** Спектры разных порядков не перекрываются друг с другом.
