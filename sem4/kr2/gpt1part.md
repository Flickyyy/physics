# Конспект по темам «Колебания и Оптика»

## Часть I. Колебания

### 1. Индуктивность цилиндрической катушки
**Дано:**  
- длина катушки ℓ = 20 см = 0,20 м  
- диаметр d = 5 см ⇒ радиус R = d/2 = 0,025 м  
- число витков N = 200  
- магнитная проницаемость μ (для воздуха μ ≃ μ₀ = 4π·10⁻⁷ Гн/м, для сердечника μ = μ₀·μ_r)  

**Формула:**  
$$
L = μ·\frac{N^2·S}{ℓ},\quad S = πR^2
$$

**Решение:**  
1. Площадь поперечного сечения  
   $$S = π·(0,025)^2 ≈ 1{,}96·10^{-3} \text{ м}^2.$$  
2. Подставляем:  
   $$L = μ·\frac{200^2·1{,}96·10^{-3}}{0{,}20} 
        = μ·\frac{40000·1{,}96·10^{-3}}{0{,}20} 
        = μ·0{,}392 \;\text{Гн}.$$
3. Если сердечник стальной μ_r ≈ 5000, то  
   $$μ = μ₀·5000 ≈ 4π·10^{-7}·5000 ≈ 6{,}28·10^{-3} \text{ Гн/м},$$  
   $$L ≈ 6{,}28·10^{-3}·0{,}392 ≈ 2{,}46·10^{-3} \text{ Гн} = 2{,}46 \text{ мГн}.$$

### 2. Взаимная индуктивность тороидальной катушки и прямого провода
**Дано:**  
- тороид с внутренним радиусом r₁, внешним r₂  
- толщина вдоль провода h  
- число витков N  
- магнитная проницаемость μ  

**Идея решения:**  
По теореме о циркуляции магнитного поля прямой ток создаёт внутри тора поле:  
$$B(ρ) = \frac{μI}{2πρ},\quad r₁ < ρ < r₂.$$
Магнитный поток через один виток:  
$$Φ = \int_{r₁}^{r₂} B(ρ)·h·dρ 
    = \frac{μI·h}{2π}\int_{r₁}^{r₂}\frac{dρ}{ρ} 
    = \frac{μI·h}{2π}\ln\frac{r₂}{r₁}.$$
Взаимная индуктивность:  
$$M = N·\frac{Φ}{I} 
    = \frac{μN·h}{2π}\ln\frac{r₂}{r₁}.$$

### 3. Зарядка конденсатора и колебательный контур (LC)
**Дано:** при t=0 замкнули ключ, конденсатор С был заряжен до Uₘ.  
Найти:  
1. ток I(t)  
2. ЭДС самоиндукции ε_L в моменты, когда W_C = W_L.

**Формулы и решение:**  
1. Уравнение колебаний:  
   $$\frac{d^2q}{dt^2} + \frac{1}{LC}q = 0, 
     \quad q(0)=CU_m,\; \dot q(0)=0.$$
   Решение:  
   $$q(t) = C U_m \cos(ωt),\; ω = \frac{1}{\sqrt{LC}}.$$
   Ток:  
   $$I(t) = \dot q = -C U_m ω\sin(ωt).$$
2. Энергии:  
   $$W_C = \frac{q^2}{2C} = \frac{C U_m^2}{2}\cos^2(ωt),\quad 
     W_L = \frac{L I^2}{2} = \frac{L C^2 U_m^2 ω^2}{2}\sin^2(ωt).$$  
   Но L C ω² = 1, значит  
   $$W_L = \frac{C U_m^2}{2}\sin^2(ωt).$$  
   Равенство W_C = W_L ⇒ cos² = sin² ⇒ ωt = π/4 + kπ/2.  
   ЭДС самоиндукции:  
   $$ε_L = -L\frac{dI}{dt} = -L(-C U_m ω^2\cos ωt) = L C U_m ω^2\cos ωt = U_m\cos ωt.$$

### 4. Гармонические колебания точки
**Дано:** T = 0,60 с, a = 10,0 см.  
Найти среднюю скорость за прохождение пути a/2:
1. из крайнего положения  
2. из положения равновесия.

**Решение:**  
Общее уравнение:  
$$x(t)=a\cos(ωt),\; ω=2π/T.$$
1. Из x=a до x=a/2:  
   Решаем a cos φ = a/2 ⇒ cos φ = 1/2 ⇒ φ = π/3.  
   Время Δt = φ/ω = (π/3)/(2π/T) = T/6 = 0,10 с.  
   Путь S = a – a/2 = a/2 = 0,05 м.  
   $$\bar v_1 = \frac{S}{Δt} = \frac{0,05}{0,10} = 0,5 \text{м/с}.$$
2. Из x=0 до x=a/2:  
   В момент равновесия φ=π/2 ⇒ до φ=π/3 проходит «назад»: считаем модуль пути  
   Время Δt = (π/2 – π/3)/ω = (π/6)/(2π/T) = T/12 = 0,05 с.  
   Путь S = a/2 = 0,05 м.  
   $$\bar v_2 = \frac{0,05}{0,05} = 1 \text{м/с}.$$

### 5. Затухающие колебания: энергия поля конденсатора
**Дано:**  
$$u(t)=U_m e^{-βt}\cos(ωt−φ_0),\; U_m=12\,\text{В},\; ω=120\,\text{с}^{-1},\; β=2{,}5\,\text{с}^{-1},\; φ_0=π/6.$$
Найти полную энергию электрического поля через время t = T/6, где T = 2π/ω.

**Решение:**  
1. Период T = 2π/120 = π/60 ≈ 0,05236 с.  
2. t = T/6 = π/360 ≈ 0,00873 с.  
3. Напряжение u(t):  
   $$u = 12 e^{-2{,}5·0{,}00873}\cos(120·0{,}00873 - π/6).$$
4. Заряд q=C u, энергия поля  
   $$W = \frac{C u^2}{2}.$$  
   (Если C не дано — оставляем в виде функции от C.)

### 6. Вынужденные колебания с затуханием
**Дано:** m = 0,1 кг, k = 5 кН/м = 5000 Н/м,  
F = F₀ sin Ωt (F₀=100 Н, Ω=100 рад/с), F_b = αV (α=50 Н·с/м).

**Уравнение:**  
$$m\ddot x + α\dot x + kx = F_0\sinΩt.$$

**Резонанс:**  
Амплитуда  
$$A(Ω) = \frac{F_0/m}{\sqrt{(ω_0^2 - Ω^2)^2 + (2βΩ)^2}},$$  
где ω₀ = √(k/m), 2β = α/m.  
Максимум достигается при  
$$Ω_{res} = \sqrt{ω_0^2 - 2β^2}.$$
Подставляете численно:
- ω₀ = √(5000/0,1) = √50000 ≈ 223,6 с⁻¹,
- β = α/(2m) = 50/(2·0,1) = 250 с⁻¹ ⇒ 2β² = 2·250² = 125000 → Ω_res не существует (β сильнее).

### 7. Соотношение резонансных и собственных частот
**Дано:** добротность Q = 10.  
В колебательном контуре без потерь резонансная частота Ωₙ = ω₀. С потерями:  
$$Ω_{res} = ω_0\sqrt{1 - \frac{1}{2Q^2}}.$$
Отношение  
$$\frac{Ω_{res}}{ω_0} = \sqrt{1 - \frac{1}{2Q^2}}
  = \sqrt{1 - \frac{1}{2·10^2}} = \sqrt{1 - 0{,}005} ≈ 0{,}9975.$$

### 8. Колебания пластины от падающих капель
**Дано:** ω₀ — собственная частота пластины,  
капли падают с периодом T = 2π/ω₀ (резонанс).  
Скорость капли при падении с высоты H:  
$$v = \sqrt{2gH},$$  
расстояние между каплями d = v·T = T·√(2gH).  
Подставляем T = 2π/ω₀:  
$$d = \frac{2π}{ω_0}\sqrt{2gH}.$$

## Часть II. Интерференция и Дифракция

### 1. Интерференция света
- **Условие:** когерентные источники (однаковая частота и постоянная разность фаз).  
- **Макс. и мин. интенсивности:**  
  $$I = I_1 + I_2 + 2\sqrt{I_1I_2}\cosΔφ.$$
- **Условие максимумов:** Δφ = 2πm, m ∈ ℤ; минимумов: Δφ = π(2m+1).

### 2. Дифракция Френеля
- Рéгион ближней зоны, волновой фронт делится на зоны Френеля.  
- **Критерий:** ширина щели a и расстояние L. Если a²/L ≲ λ → дифракция значима.  
- Считаем сумму полей от зон Френеля.

### 3. Дифракция Фраунгофера
- Дальняя зона (эксперимент с коллиматором и линзой).  
- **Условие интенсивных максимумов/минимумов для щели ширины a:**  
  $$a\sinθ = mλ\;(минимумы),\quad m = ±1,±2,….$$
- Для двух щелей (интерференция + дифракция):
  $$d\sinθ = kλ\;(интерф.),\quad a\sinθ = mλ\;(дифракц.).$$
